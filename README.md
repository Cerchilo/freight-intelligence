# Freight Intelligence Centre

Static website starter built with HTML5, Bootstrap 5.3, CSS3 and Vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Current implementation
- Responsive homepage
- Navigation and hero section
- Seven tool cards
- Search and category filtering
- About section and FAQs
- Centralized CSS variables

## Planned tools
1. CBM Calculator
2. Container Load Optimizer (realistic Three.js visualization)
3. Volumetric Weight Calculator
4. Import Duty Calculator
5. Export Price Calculator
6. Air vs Sea Comparison
7. Demurrage & Detention Calculator

## Notes
The calculator pages are planned routes and will be implemented one by one. Calculations are estimates and must be checked against carrier terms, equipment specifications and applicable regulations.
