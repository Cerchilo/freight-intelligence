# Tool pages

Create one HTML page per calculator in this folder. Keep calculation logic in its matching file under `assets/js/calculators/`.

The homepage cards are already linked to these planned routes. The next implementation step is the CBM Calculator, followed by the volumetric weight calculator.

Suggested shared page structure:
- Site header / breadcrumb
- Tool title and short explanation
- Input panel
- Results panel
- Formula and assumptions
- Related tools
- Site footer
